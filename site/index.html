02 / LIVE CONTROL

Let an agent read and replace
a managed patch scope.

The MCP server compiles desired DSL and sends ordered plans to one native maxforge.sync object in each patch. The external inspects and mutates through the Max SDK—no JavaScript bridge or screenshot required.

MCP configuration

Run the published server directly with npx. Node.js 20 or newer is required.

mcp.jsonJSON
{
  "mcpServers": {
    "maxforge": {
      "command": "npx",
      "args": [
        "-y",
        "--package=maxforge@latest",
        "maxforge-mcp"
      ]
    }
  }
}
Experimental means experimental.

Protocol v1 validates complete plans before mutation but does not roll back a partial runtime failure. Inspect first, preview destructive operations, then apply complete desired state.
